# SignalIndex conceptual architecture — public, source-free

Operator selects source URL(s) → local retrieval/observation → content SHA-256 → proposed change receipt → human review/acceptance → local SQLite evidence history → CSV/summary export.

This is a conceptual flow, not an implementation specification. Hash differences may reflect irrelevant HTML changes and do not independently authenticate a vendor or price. Human review is required. The public diagnostic does not access a commercial database or proprietary engine.
